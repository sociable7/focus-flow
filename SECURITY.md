# Security Policy

## Supported Versions

Focus Flow is an early-stage macOS application under active development.

Security fixes are provided for the latest release / `main` branch only.
Earlier versions, snapshots, and forks are not supported. If you are
running an older copy, please update to the latest version before
reporting an issue.

| Version | Supported |
| ------- | --------- |
| Latest release / `main` | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do not open a public
GitHub issue, discussion, pull request, or otherwise publicly disclose
the details before the issue has been addressed.

To report a vulnerability, contact the maintainer privately:

- Security contact: `[TO BE ADDED — security contact email or private reporting link]`

Please include, where possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including macOS version, Python version, and
  Focus Flow version or commit
- Any relevant logs, screenshots, or proof-of-concept details

You will receive an acknowledgment of your report, and we will keep
you informed of the remediation status as appropriate.

## Disclosure Policy

We ask that you give us a reasonable opportunity to investigate and
address a reported vulnerability before any public disclosure. Please
do not publicly disclose vulnerabilities until we have had a chance
to provide a fix and guidance.

## Scope

This policy covers security issues in Focus Flow and this repository,
including the application code, packaging configuration, and related
assets maintained here.

Out of scope: third-party dependencies, macOS itself, Qt/PySide6, and
other external tools or services. Vulnerabilities in those components
should be reported to their respective maintainers, unless the issue
is specific to how Focus Flow uses or bundles them.

Thank you for helping keep Focus Flow and its users safe.
