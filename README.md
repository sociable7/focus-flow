# Focus Flow

Focus Flow is a professional Pomodoro productivity desktop application built with Python and PySide6.

## Features

- Customizable focus duration
- Customizable short break
- Customizable long break
- Start, pause and reset controls
- Multiple predefined themes
- Custom accent color
- Custom background color
- Custom notification sound
- Persistent settings
- Session tracking
- macOS-friendly desktop interface

## Technologies

- Python 3
- PySide6
- Qt
- QSettings
